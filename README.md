## Projects

### [egovmed](https://github.com/Bisaya-Hackers/egovmed)
Healthcare triage and appointment system for the Philippine public healthcare system — AI symptom triage, government SSO, biometric ID verification, blockchain-anchored records. **Lead developer** · 1 of 10 winning teams, **eGovPH Hackathon 2026**.
`React` `Node.js` `Solidity` `Redis`

### Penny — AI-Powered Financial Barrier App
Parses GCash, Shopee, and bank notifications in real time into a live "safe-to-spend" balance, using the Claude API to auto-classify transactions. **Finalist, Hack it UP** (UP Manila hackathon) — targeting the gap where only 2% of Filipino adults pass basic financial literacy questions.
`Python` `Flutter` `Claude API`

### [UPGrade](https://github.com/StarRayX/UPGrade)
Gamified learning platform using the Gemini API to generate quiz content at scale. Shipped end-to-end with a cross-functional team in 48 hours. **1st Runner-Up, TECHATHLON 2026**.
`React` `TypeScript` `Gemini API`

### NASA Asteroid Threat Prediction System
Impact risk scoring model built on NASA orbital parameter data — feature engineering, a full preprocessing pipeline, and precision/recall/F1 evaluation against threat level classification.
`Python` `scikit-learn` `pandas`

### md2pdf
CLI Markdown-to-PDF converter with a hand-written tokenizer, parser, and document tree, backed by a pytest test suite.
`Python` `pytest`
